# Code of Conduct

This is a small community of people who like an old game. Keep it friendly.

- Be respectful and welcoming, whatever someone's experience, background or identity.
- Assume good intentions, give constructive feedback, and accept it gracefully.
- No harassment, insults, personal attacks, or sexualized language or imagery.
- Don't share others' private information.
- No piracy: don't ask for or share game files with people who don't own the game.

Maintainers may edit or remove contributions, and block people, who don't follow these rules.

To report a problem privately, use
[GitHub's private reporting form](https://github.com/mihaicristianfarcas/homm3-browser/security/advisories/new)
(meant for security issues, but only the maintainers see it, so it works for this too).
Reports are handled confidentially.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
